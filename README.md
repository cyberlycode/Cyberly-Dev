# PIO Bloatware Windows Remover

**PIO Bloatware Windows Remover** adalah aplikasi Windows ringan dan **portable** yang dirancang untuk membantu pengguna mendeteksi dan menghapus bloatware atau aplikasi tidak perlu dari sistem mereka. Dibangun dengan Python dan terintegrasi dengan PowerShell, aplikasi ini memberikan solusi pembersihan sistem yang sederhana, efisien, dan mudah dikenali.

## Fitur

- **Portable & Mudah Digunakan**  
  Tidak perlu instalasi. Cukup unduh dan jalankan aplikasinya.

- **Scan Bloatware**  
  Memindai sistem Windows dengan cepat untuk mengidentifikasi aplikasi bawaan atau yang tidak perlu.

- **Analisis Backup Aplikasi**  
  Membaca `backup_apps.json` untuk menganalisis aplikasi yang sudah dibackup sebelumnya, memudahkan pemulihan atau peninjauan.

- **Integrasi PowerShell**  
  Menggunakan skrip PowerShell untuk menjalankan tugas tingkat sistem. Popup PowerShell singkat mungkin muncul saat pemindaian, ini adalah perilaku normal.

- **Ikon Kustom**  
  Ikon unik menampilkan kalajengking yang menjepit logo Windows.

- **UI Sederhana dan Intuitif**  
  Antarmuka minimalis yang dirancang agar mudah digunakan dan cepat dalam menampilkan hasil.

## Cara Penggunaan

1. **Unduh** aplikasinya.  
2. **Jalankan sebagai Administrator** agar fungsinya maksimal.  
3. Klik **Scan** untuk menganalisis aplikasi yang terpasang.  
4. Tinjau bloatware yang terdeteksi dan kelola atau hapus aplikasi yang tidak perlu.  
5. Popup PowerShell mungkin muncul sebentar saat operasi aplikasi ini berjalan sangat normal dan akan menutup secara otomatis.

> **Catatan:** Disarankan menjalankan aplikasi dengan hak Administrator untuk efektivitas maksimal. Pastikan backup sudah diperbarui sebelum menghapus aplikasi. Saat ini dirancang untuk sistem Windows 10 dan Windows 11, untuk platform OS lain belum didukung.
