PIO BAT Suite v1.0 (Multi-Platform)
PIO BAT adalah tools sederhana namun ampuh untuk mengecek, mendiagnostik, dan mengelola baterai pada laptop yang menggunakan sistem operasi Windows maupun Linux.

Tools ini diciptakan untuk memberikan kemudahan bagi kamu dalam memantau kesehatan sel baterai, melihat kapasitas asli pabrikan vs kapasitas saat ini, hingga mengatur charging threshold agar umur baterai laptop jauh lebih awet.

Ini adalah persembahan spesial untuk kalian semuanya para pegiat open-source, teknisi, dan pengguna laptop harian!

📁 Navigasi Direktori
Kamu dapat melihat panduan lengkapnya sesuai folder atau direktori yang sudah disediakan:

🐧 PIOBATLINUX/

Versi CLI berbasis Go (Golang) khusus OS Linux (Pop!_OS, Ubuntu, Debian, Arch Linux, Fedora, Linux Mint, dll).

🪟 PIOBATWIN/

Versi CLI berbasis PowerShell & Batch Runner khusus OS Windows (Windows 10 & Windows 11).
